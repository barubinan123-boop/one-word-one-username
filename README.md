Entry for make.fun's [One Word, One Username, One Reward](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae) bounty. The program writes the entrant's own make.fun username, `hsnmbrk07`, as a single word to `/output/entry.txt` — nothing else, no explanation, no links, no pitch.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (it runs TypeScript directly). The program creates `/output` if it does not exist yet, then writes exactly `hsnmbrk07` (9 bytes, no trailing newline) to `/output/entry.txt`, in UTF-8. It is fully deterministic: no network access, no external input, no randomness.
